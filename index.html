Synchronisation Google Drive

L'application garde un fichier atelier-pc.json dans votre Drive et le fusionne entre vos appareils. Configuration à faire une seule fois :

  1. Sur console.cloud.google.com, créez un projet puis activez Google Drive API (API et services → Bibliothèque).
  2. Écran de consentement OAuth : type Externe, puis ajoutez votre adresse Gmail dans « Utilisateurs test ».
  3. Identifiants → Créer → ID client OAuth → Application Web. Dans « Origines JavaScript autorisées », ajoutez l'adresse de votre site (ex : https://votrenom.github.io).
  4. Collez l'ID client ci-dessous. Utilisez le même sur chaque appareil.
